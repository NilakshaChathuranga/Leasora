# Leasora

Leasora is a leasing application project under development.

## Planned technology stack

- Mobile app: Flutter
- Backend API: ASP.NET Core
- Database: PostgreSQL
- Admin dashboard: React

## Repository structure

- apps/mobile/ — Flutter mobile application
- apps/admin/ — React admin dashboard
- services/backend/ — Backend solution and tests
- docs/ — Project plans, architecture, and setup guides
- infra/ — Database setup and deployment configuration

## Current status

Initial repository setup. Application projects have not been generated yet.
